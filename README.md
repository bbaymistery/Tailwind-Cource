# 3 - Converting a Figma Design to Next.js with Tailwind CSS

This project is a conversion of a Figma design into a fully responsive, modern web application built using **Next.js** and styled with **Tailwind CSS**.

## 🔗 Sources & Resources

* **Figma Design Link:** [Codedamn Frontend Assessment](https://www.figma.com/file/TXLwYa51OaUfXRjO5AQvL0/Codedamn-Frontend-Assessment)
* **YouTube Reference Video:** [YouTube Tutorial - Converting Figma to Next.js & Tailwind](https://www.youtube.com/watch?v=fgrlH9pbVU0)

## 🛠️ Technology Stack

* **Framework:** Next.js
* **Styling:** Tailwind CSS (Vanilla CSS utilities)
* **Components:** Custom modular components
* **Typography & Icons:** Modern typography and pixel-perfect SVG icons mirroring the Figma design
