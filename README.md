# Tailwind CSS Course from Scratch

This repository contains the code for a Tailwind CSS course from scratch.
The `1-hux` branch is a tutorial of Tailwind.
Source tutorial video: https://www.youtube.com/watch?v=WvBnTJK7Khk&t=6149s
Note: This project is written using plain HTML, CSS, and Tailwind CSS. It is **not** a React application.
